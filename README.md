# My Simple Portfolio 🚀

Selamat datang di repositori portofolio pribadiku! Web ini berisi kumpulan proyek yang pernah aku kerjakan, mulai dari desain grafis hingga pengembangan web sederhana (terlalu sederhana :p).

## 🛠️ Tech Stack & Tools
Proyek ini dibangun menggunakan kombinasi tools desain dan teknologi web berikut:

- **Frontend:** HTML5, CSS, JavaScript (Vanilla)
- **Design Tools:** Figma, Ibis Paint X, Canva
- **Deployment:** [Vercel](https://personalweb-alpha-seven.vercel.app/)

## ✨ Key Features
- **Direct Email Integration:** Fitur "Email Me" menggunakan EmailJS, sehingga pengunjung bisa mengirim pesan langsung tanpa harus membuka aplikasi email eksternal.
- **Project Showcase:** Menampilkan sertifikasi dan karya desain dari berbagai platform.

## 📂 Project Highlights
Beberapa proyek yang ditampilkan di sini antara lain:
- **UI/UX Design:** Proyek desain antarmuka menggunakan Figma.
- **Digital Art:** Ilustrasi 2D yang dibuat menggunakan Ibis Paint X.
- **Web Development:** Proyek web fungsional seperti **MathGi**.
